# 💰 Миний санхүү (My Finance)

Монгол хэлтэй хувийн санхүүгийн апп. Python + Streamlit + SQLite ашиглана.

## Гол функцууд

1. **Банкны хуулга импорт:** CSV/XLSX импортлох, огноо/дүн/утгын багана сонгох, хуучин гүйлгээг хадгалах, дахин импортолсон давхардлыг алгасах. Хуулгын ID багана байвал сонгож болно.
2. **Сарын төсөв:** Дараа сарын төсвийг ангиллаар төлөвлөх, бодит гүйцэтгэл болон зөрүүг харах, ангилал засах.
3. **Урт хугацааны зорилго:** Байр, машин зэрэг олон зорилго, анхны хуримтлал, сарын хуримтлал, жилийн өгөөж, зээлээр санхүүжүүлэх хувь, хугацаа, хүүг хослуулан тооцох. Зорилгын сарын хуримтлалыг төсвийн хэсэгт нэгтгэн харуулах.

## Ажиллуулах

Python 3.10 ба түүнээс шинэ хувилбар шаардлагатай.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Нээгдэх хаяг: `http://localhost:8501`

## Импортын формат

CSV эсвэл XLSX файлын жишээ (`sample_statement.csv`):

| Огноо | Гүйлгээний утга | Дүн | Ангилал | Гүйлгээний ID |
|---|---|---:|---|---|
| 2026-10-01 | Цалин | 2500000 | Бусад | TX001 |
| 2026-10-02 | Хүнсний дэлгүүр | -85000 | Хүнс | TX002 |

Банкны хуулгын баганын нэр өөр байж болно: апп дотор тааруулан сонгоно. Эерэг дүн = орлого, сөрөг дүн = зарлага. Эсвэл тус тусдаа орлого/зарлагын багана сонгоно.

**Давхардал:** Импортын таних түлхүүр нь огноо, утга, дүн, гүйлгээний ID (байвал) болон ижил мөрийн давтамжаас хамаарна. Банкны өвөрмөц гүйлгээний ID-г сонгох нь хамгийн найдвартай. Ижил гүйлгээний тайлбар/дүн/огноотой мөрүүд өөр хуулгад гарсан тохиолдолд ID байхгүй бол зарим давхардал ялгагдахгүй байж болно.

## GitHub-д байршуулах

GitHub дээр **шинэ, хоосон repository** үүсгээд тухайн хавтсанд:

```bash
git init
git add .
git commit -m "Build personal finance app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/my-finance-app.git
git push -u origin main
```

Collaborator нэмэх: Repository → **Settings → Collaborators → Add people** → `ankhbayar-ufe` → invitation илгээх.

Багшид өгөх линк: `https://github.com/YOUR_USERNAME/my-finance-app` (`YOUR_USERNAME`-г өөрийн GitHub нэрээр солино).

## Өгөгдөл ба хязгаарлалт

- Өгөгдөл `finance.db` SQLite файлд локалаар хадгалагдана. `.gitignore`-д орсон тул хувийн банкны мэдээлэл GitHub руу орохгүй.
- Апп одоогоор нэг хэрэглэгчийн **локал** хувилбар. Онлайн олон хэрэглэгчтэй deployment-д хэрэглэгчийн нэвтрэлт болон тусгаарласан өгөгдлийн сан шаардлагатай.
- Зорилгын тооцоо нь таамаглал; банкны баталгаат зээлийн санал биш.
